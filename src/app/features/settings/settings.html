Réglages

Chaque saisie est enregistrée automatiquement dans la base SQLite de cet appareil (data/planning.sqlite). Le fichier est le même quel que soit le port utilisé. L’export JSON reste une copie de secours.

Trajet par défaut

Valeurs appliquées à chaque journée sur site. Une journée peut toujours être ajustée individuellement depuis le calendrier.

Les week-ends et les 11 jours fériés français sont déduits automatiquement du calendrier.

Barème kilométrique

Formule utilisée pour la déclaration : (kilomètres × taux) + forfait. Adaptez les valeurs au barème de votre puissance fiscale.
